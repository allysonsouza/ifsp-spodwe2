# Módulos - Flags

Dado um módulo inicial com a função `drawFlag`, que criar um novo elemento `<img>` e adiciona ele à página, implemente as seguintes funcionalidades no código, importando o módulo no seu `main.js` e modificando o código fonte do módulo:

1. Modifique a função `drawFlag` do módulo para permitir que seja escolhido (ou não) em qual elemento será inserida a bandeira
2. Modifique a função `drawFlag` do módulo para permitir que uma classe seja adicionada (ou não) ao elemento `<img>`
3. Modifique a função `drawFlag` do módulo para permitir que uma função de _callback_ seja passada (ou não) para ser vinculada ao evento `click` da bandeira a ser inserida
